# Checklists and lifecycle tables

## Checklists

Add a **Checklist** component inside a content-section column. Choose either check marks or numbered steps, then add up to 24 concise items. Each item needs text; its short title is optional. Use a Rich text component instead when an item needs long-form or formatted content.

## Lifecycle records

Lifecycle rows are managed in **Resources → Lifecycle Items**. Editors and administrators can create, edit, draft, and publish records; only administrators can delete them. A public row must be both published and **Active**.

The product label groups related rows under one heading. The service name, lifecycle duration, version, end-of-life date, and optional end-of-access date form the table columns. Description is optional.

## Lifecycle page component

Add a **Lifecycle table** component and select the managed lifecycle records in the order they should be considered. Unpublished, inactive, or unresolved relationships do not render publicly. The component separates rows into upcoming and previous periods from the end-of-life date, groups them by product label, and provides accessible table captions. Enable **Show descriptions** only when the selected records contain supporting detail that belongs in the table.
